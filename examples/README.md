# Examples

Static samples and shell scripts for the live API.

| Path | Description |
|------|-------------|
| [`curl/`](curl/) | Executable curl workflows |
| [`python/`](python/) | Python SDK example (`track_product.py`) |
| [`typescript/`](typescript/) | TypeScript SDK example (`track-product.ts`) |
| [`responses/`](responses/) | Example JSON bodies (for docs and tests) |

**Base URL:** `https://pricewatcha.com/api/v1`

Set `PRICEWATCHA_API_BASE` to override:

```bash
export PRICEWATCHA_API_BASE=https://pricewatcha.com/api/v1
```
